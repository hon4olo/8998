# ZNAYA Motion Studio

Read repository AGENTS.md and docs/ASTRA_HANDOFF.md first. Invoke in Codex using `$znaya-motion-studio <topic-or-script> --voiceover <file> --format vertical --reference <path>`. A custom `/znaya-motion-studio` slash command is not registered by this repository; do not pretend it is executable. The shell intake is `npm run new -- ...`, not an automatic script-to-film generator.

1. Run `npm run check`. In a fresh cloud environment run `bash scripts/setup.sh`; tool installation is ephemeral. Do not reinstall tools when startup checks pass. Read docs/environment_report.md and the pinned official Tesseract skills as required. Never use Brainmerge resources.
2. Claim a new project using `npm run new -- "topic" --voiceover supplied.wav --format vertical --reference refs/ --id film-id`. This copies supplied material, measures narration, extracts reference video frames every 0.5 seconds and creates unapproved production documents. Inspect actual reference sheets and audio waveform; listen when tooling permits, disclose otherwise.
3. Gate 1: fill brief, approved asset list, rights, source-backed scientific claims, actual transcript. Missing materials block dependent work. Obtain user's material approval, recording actor/time/revision in project docs. No invented brand, interface, statistics or anatomy.
4. Analyze reference composition, palette, type, shot lengths, movement, transitions and rhythm. Write docs/style_guide.md and docs/shotlist.md in the project, citing actual frames. Take grammar only. Gate 2: user approves both documents. Test colors/fonts are not brand rules.
5. Author variable-duration storyboard with initial/final states, semantic purpose, camera, transition and narration anchors. Implement an original scene module; register it in scenes/index.ts and set project.composition. Never reuse the technical fixture as a final scientific video. All rendering must be a function of timestamp and seed. Use src/animation/math.ts for closed-form springs and matched-point morphs; no timers, Math.random, CSS transitions or frame accumulation.
6. Gate 3: `npm run preview -- --project projects/film-id/project.json`. Open actual entry/hold/exit images for every scene, score six criteria, fix the three worst defects locally; get approval of keyframes before animatic.
7. Gate 4: `npm run render -- --project projects/film-id/project.json --format animatic --name film-id-animatic --gate 4`. This produces independent 960×540 composition with original narration. Approve the reviewed animatic.
8. Gate 5: full vertical render, inspect contact sheet (2 fps, 6 across), phone previews, dense transition strips, first/last frames and audiovisual clock checks. Correlation and energy are not semantic speech alignment. Use supplied/manual word marks; `scripts/align.py` defines a future local forced-aligner ABI. No mandatory paid API. Optional `scripts/sfx.py` creates short accents only, never music.
9. After every preview, read automated-checks.json and open rendered images; score hook, phone readability, composition, motion, scene variety and brand/voice fidelity separately. Scores are subjective evidence, not proof of 8/10. Record timecodes, worst three defects, local patches and re-rendered evidence. Do not claim video playback or audio audition if only stills were inspected. If inspection cannot happen, leave review pending; do not ship.
10. Gate 6: after polish approval export vertical/wide/square as separate layouts. Verify actual ffprobe streams and original audio clock, deterministic frame SHA-256, no blank endpoints, loop when required, and poster. Provide sources, retained review revisions, tool versions, benchmark and limitations. Tesseract adapter flattens browser content into imported Video; only native layers added around it are editable. Never claim Canvas paths become native Tesseract layers.

Technical smoke tests may traverse gates automatically on explicitly neutral fixtures; no real ZNAYA film is authorized by a smoke test. Stop for approvals only when the real production gate requires them; continue routine fixes within approved scope.
